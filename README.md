# 🏚️ Bhargavi Nilayam

### A Psychological Horror Game Inspired by Old Kerala

![Game Type](https://img.shields.io/badge/Genre-Psychological%20Horror-red)
![Platform](https://img.shields.io/badge/Platform-Web%20Browser-blue)
![Status](https://img.shields.io/badge/Development-In%20Progress-orange)

**Bhargavi Nilayam** is a terrifying 3D horror game set inside an abandoned hospital inspired by 1980s Kerala.

Explore a forgotten medical facility filled with disturbing secrets, paranormal encounters, abandoned rooms, mysterious sounds, and horrifying discoveries.

Every floor hides something darker. Every sound could be a warning. And not everything inside the hospital is dead.

---

## 🎮 Game Overview

* **Game Name:** Bhargavi Nilayam
* **Genre:** 3D Horror / Psychological Horror / Survival
* **Setting:** Abandoned Hospital, Kerala
* **Era:** 1980s atmosphere
* **Platform:** Web Browser
* **Development Status:** In Development

## 🏥 Game Environment

The game takes place inside a massive, abandoned four-floor hospital.

Explore:

* Abandoned hospital corridors
* Dark patient rooms
* Emergency wards
* Old operation theatres
* Morgue and autopsy rooms
* Staircases and isolated floors
* Forgotten medical storage rooms

The environment combines old Kerala architecture, decaying hospital interiors, atmospheric lighting, and supernatural horror.

## 👻 Horror Features

* Atmospheric darkness and fog
* Creepy background sound effects
* Paranormal encounters
* Unexpected ghost appearances
* Horror events and scripted scares
* Abandoned hospital environment
* Interactive objects and exploration
* Immersive horror missions

## 🩸 Morgue Mission

One of the most disturbing locations in the game.

Players must investigate the abandoned morgue, where:

* A body trolley opens automatically.
* A supposedly dead patient suddenly comes alive.
* Another body lies on the autopsy table.
* Strange movements and unexplained sounds create tension.

The morgue hides secrets that players must uncover.

## 🏢 Building Exploration

The hospital features four floors connected by staircases.

Each floor contains different rooms, environmental storytelling, hidden clues, and frightening encounters.

Players must explore carefully to progress through the hospital.

## 🎧 Audio & Atmosphere

The game uses horror-inspired audio elements, including:
